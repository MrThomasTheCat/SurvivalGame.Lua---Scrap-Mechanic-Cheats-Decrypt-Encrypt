INSTALLATION PROCESS:
STEP 1: Go to "\steamapps\common\Scrap Mechanic\Survival\Scripts\game" and drag and drop the SurvivalGame.Lua file you downloaded from this GitHub into the folder.
STEP 2: Go to "Properties" for Scrap Mechanic, find "Launch Options" and type "-dev" into the box.

IF ISSUES ARISE:
1. Ensure you restart your game if you updated the SurvivalGame.Lua while you were still in the game.
2. Verify integrity of game files
